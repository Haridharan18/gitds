# Data Structures Project — Linked List (C)

## 📚 Overview
This project implements a **Linked List** in the C programming language.  
It demonstrates fundamental operations like insertion, deletion, searching, and traversal.

## 🧠 Concepts Covered
- Dynamic memory allocation
- Pointer manipulation
- Node creation and linking
- Traversal of linked list
- Deletion of specific nodes
